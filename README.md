
# 🏥 Hospital Management System

A Hospital Management System built using Python, Streamlit, MySQL, Pandas, and Matplotlib.

---

# 📌 Project Overview

This project helps hospitals manage:

- Patient Records
- Doctor Records
- Appointment Booking
- Appointment Status
- Billing System
- Dashboard Analytics

The system reduces manual work and improves hospital management efficiency.

---

# 🚀 Technologies Used

- Python
- Streamlit
- MySQL
- Pandas
- Matplotlib

---

# ✨ Features

## 👤 Patient Management
- Add Patient
- Search Patient
- Delete Patient

## 👨‍⚕️ Doctor Management
- Add Doctor
- Manage Doctors

## 📅 Appointment Management
- Book Appointment
- Update Appointment Status
- View Appointment Details

## 💰 Billing System
- Generate Patient Bills
- Automatic Fee Calculation

## 📊 Dashboard Analytics
- Total Patients
- Total Doctors
- Total Revenue
- Patients By Gender Graph
- Appointment Status Pie Chart
- Revenue By Doctor Graph

# ▶️ How to Run Project

## Step 1
Clone repository

```bash
git clone https://github.com/your-username/Hospital-Management-System.git
```

## Step 2
Install requirements

```bash
pip install -r requirements.txt
```

## Step 3
Run Streamlit app

```bash
streamlit run hospital.py
```
